# Skill: Data Privacy Review

## Purpose
Assess systems and code for compliance with PDPA (Singapore), bank data classification policy, and PII handling standards.

## Trigger
Use when asked to: privacy review, PDPA check, data classification, PII handling, data retention.

## Checks
1. PII identification and classification (Public / Internal / Confidential / Restricted)
2. Data minimisation — only collect what is needed
3. Consent management
4. Retention and deletion policies
5. Cross-border data transfer controls
6. Encryption of PII at rest and in transit
7. Access logging for sensitive data
8. Anonymisation / pseudonymisation adequacy

## Output Format
Privacy risk register: data element, classification, risk, control gap, recommendation.
