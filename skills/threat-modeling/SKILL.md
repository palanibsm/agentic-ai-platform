# Skill: Threat Modeling

## Purpose
Perform STRIDE-based threat modeling on systems, APIs, and data flows.

## Trigger
Use when asked to: threat model, identify threats, STRIDE analysis, attack surface review.

## Process
1. Define system boundaries and assets
2. Draw data flow diagram (DFD)
3. Apply STRIDE per component:
   - Spoofing, Tampering, Repudiation, Info Disclosure, DoS, Elevation of Privilege
4. Rate each threat (likelihood × impact)
5. Propose mitigations
6. Map to MAS TRM control objectives

## Output Format
DFD (Mermaid) + STRIDE table with threat, rating, mitigation, owner.
