# Skill: Incident Response Assistant

## Purpose
Guide responders through structured incident response for security and operational incidents.

## Trigger
Use when asked to: incident response, security incident, P1 runbook, postmortem, RCA.

## IR Phases
1. **Detection** — confirm the incident, classify severity (P1–P4)
2. **Containment** — isolate affected systems, revoke compromised credentials
3. **Eradication** — remove root cause (malware, misconfiguration, bad deploy)
4. **Recovery** — restore service, validate integrity, monitor closely
5. **Post-Incident** — timeline, RCA, lessons learned, MAS reporting if required

## MAS Reporting Triggers
- Material IT incidents must be reported to MAS within 1 hour of discovery
- Follow MAS Notice 655 notification obligations

## Output Format
Incident timeline table + action checklist per phase + RCA template.
